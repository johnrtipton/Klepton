# Graphics performance follow-up

Baseline: `16c2f1e`, the validated PR #1 follow-up. Identical test harnesses
compiled with O2 against the baseline and this change. Tests call production
private functions by including their source; they do not reimplement the new
algorithms. Three alternating baseline/follow-up runs, each best of seven
rounds. Builds finished before timing. Results below are means of the three
best-round measurements on this host, in ns/op.

| Operation | Baseline | Follow-up | Ratio |
|---|---:|---:|---:|
| GLES DrawElements wrapper | 121.04 | 15.54 | 7.8x |
| GLES DrawElementsInstanced wrapper | 117.37 | 12.42 | 9.4x |
| GLES DrawArrays wrapper | 12.79 | 12.33 | essentially unchanged |
| Vulkan registry hit, 2,000 entries | 402.08 | 5.48 | 73x |
| Vulkan registry miss, 2,000 entries | 405.27 | 5.73 | 71x |
| Vulkan registry hit, 12,000 entries | 2376.75 | 5.59 | 425x |
| Vulkan registry miss, 12,000 entries | 2384.80 | 5.76 | 414x |

## GLES change and validation

`klfb_note_draw` now skips its live framebuffer query, thread ID and diagnostic
census unless KL_GLFB_DRAW_CENSUS=1, KL_GL_CENSUS>0 or KL_GLFB_BLIT_PROBE=1.
BLIT_PROBE is the only reader of g_last_draw_fb, so enabling it also retains
tracking. No rendering/capture-service call or vertex-binding translation is
removed. Error argument formatting occurs only with KL_GLFB_ERRPROBE enabled;
its configuration latch uses pthread_once.

During each benchmark run both versions forwarded 4.2 million draws. Baseline
issued 4.2 million framebuffer queries and 2.8 million snprintf calls; the
follow-up issued zero of each with diagnostics disabled. DrawArrays had no
argument formatting before; no reliable speedup is claimed for it. Driver
calls are controlled test functions, excluding actual GL/ANGLE work and GPU
execution. The per-draw census is now opt-in: enable it before launch when
investigating missing images. DEBUG_ENV_VARS.md and kl_glfb.h document that
intentional diagnostic behavior change.

All seven wrapped draw variants forward their arguments in the test. Five
launch modes cover probes off, explicit draw census, object census, blit
tracking and error probes. They verify live GL framebuffer values rather than
only cached bindings, fallback when the driver query fails, zero disabled
formatting/query work, and pending/new error consumption only with probes on.
The modes are part of make check-host.

## Vulkan change and validation

Replace the mutex-protected 16,384-entry linear image registry with a 32,768-slot
open-addressed index. Keep the same mutex, registration capacity, duplicate
counting, NULL handling, fail-open-at-full policy and recovery when capacity
falls. Back-shift deletion prevents tombstones accumulating during level churn.
The table costs 384 KiB more static memory (512 KiB versus 128 KiB).

The test compares production membership/count against the old implementation
for 50,000 randomized operations, wraparound collisions/deletions/reinsertion,
capacity/ignored adds/full-mode/recovery and 10,000 duplicate/handle reuse
cycles. Eight concurrent threads also register/check/delete shared handles.
Both old and new versions pass the differential oracle; the final shared-handle
stress passes at O2. Membership is used by image-view validation and capture,
shadow/copy and texture-resolution paths. This measures the registry mutex and
lookup only, with single-thread timing and no Vulkan/GPU operations. It does
not establish the speedup of an entire frame or an image creation call.

## Build and acceptance evidence

- O2: all 12 existing guest-free host gates and five GLES modes pass. The UDP
  broadcast gate initially hit sandbox bind denial, then the suite passed with
  local network permission. No failure was bypassed.
- The Vulkan differential/concurrency test passes at O2 with installed headers.
- Shipping O2 runtime compiles and all-load links for visionOS device and
  simulator with the full Vulkan implementation and without Vulkan headers.
- Full guest compatibility, live ANGLE rendering, headset gameplay/FPS,
  end-to-end audio and memory behavior are not validated by these tests.
- QueueWaitIdle/frame synchronization stays unchanged: the current Vulkan
  compositor has no matching shared event and relies on queue completion before
  sampling. A safe replacement needs device tracing and lifetime validation.
- Controlled headset protocol is in GAMEPLAY-VALIDATION.md. No game was replaced
  or launched during this pass.

Reproduce: make check-host-O2, make check-graphics-O2 and make perf-graphics-O2.
The graphics targets require headers from make mvk; pass MVK_INC=-I/path/include
when reusing an installed header tree. GL-only checks work in a bare checkout.
